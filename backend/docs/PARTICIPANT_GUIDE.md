# Participant guide

1. Register with email/password or use Google sign-in after the organiser configures OAuth.
2. Select a published contest. For a private contest, enter the personal access code given directly by the organiser.
3. Open the problem list after the contest starts. Public sample tests are available for Run; hidden tests are used only for Submit.
4. Run requests are unscored. Submit requests are stored with the server receipt time and judged asynchronously.
5. Check your submission status by polling the returned run/submission ID. A queued response means the code has been safely accepted for judging, not that it has already passed.
